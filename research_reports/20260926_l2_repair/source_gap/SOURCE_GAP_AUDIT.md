# L2 固定股数 / T+1 收盘纸面账户：独立数据覆盖审计

**结论：现有公开及本地资料足以构造局部诊断，尚不能完成全历史、三版可认证的固定股数账户。`2010-01-06` 首个持股缺原始收盘可按已证停牌沿用上一有效价，不构成纸面算术阻断；首个换仓 `2010-01-15` 则有具体受阻订单。L1 候选池、PIT ST、权益事件仍为 FAIL，故本报告不生成修正持仓、净值或绩效。**

## 口径和复现

- 冻结旧样本截止 `2026-09-24`。用户本轮选择：T 收盘生成目标，T+1 收盘纸面尝试成交，持仓期间固定股数，下一交易日起新股数承担收益。此口径允许停牌股继续留在账上，以已核实的上一笔交易价格估值；不能把停牌日的填充 OHLC 当作成交。

## 首个不能闭合的日期如何理解

1. **L1 先行阻断：`2010-01-04`。** 期初旧 100 只不是已认证的 PIT 前 100。选了新的 L2 时钟，不会修复这个目标池。
2. **纸面计算可定义：`2010-01-05`。** 100/100 有原始收盘，给定本金、股数取整、费用与现金规则即可产生自融资的**候选**纸面开仓。缺真实成交回执阻断实盘可执行性结论，不阻断纸面算术检验。
3. **首个缺价不是硬阻断：`2010-01-06`。** `600982` 已证暂停交易，上一有效价可用于当日持仓盯市，前提是状态、权益事件及补价规则被显式冻结和核对。
4. **首个换仓的具体逐股状态：`2010-01-15`。** 两笔拟卖停牌，另有一笔拟买处于诊断涨停；纸面订单和旧状态已经分叉。缺该日 raw close 的旧持仓可保留上一笔真实价盯市，前提是独立核实停牌与期间权益事件。

## 可在公开资料下继续补什么

- 公司公告与交易所原始记录可逐股补 PIT ST、实施日、分红送转、配股及停复牌；已有 L1 局部证据不能外推为 2010–2026 全池零遗漏。[上交所公示目录](https://www.sse.com.cn/market/publicdata/)列有停复牌与股票信息入口，是否提供本任务所需全史、可追溯的逐日文件需逐段核验。
- BaoStock 原价日线与本地 raw close 可支持纸面价格验证；`tradestatus=0` 的伪 OHLC 不代表成交。本地 `clock` 审计已核首个三窗口，但没有全史收盘竞价量与真实委托回执。纸面价格模型应明确“不证明可成交”，将买卖受阻与留仓记账。
- 如要声称**自融资、可执行的 0.8 倍期货对冲**，须先定义历史每日期货合约选择/滚仓、保证金与结算，不能从指数收益和固定拖累反求。若选择纯理论指数空头纸面覆盖，也必须独立标记且不得称真实可执行收益。

**审计边界：** 本报告量化的是现存旧冻结输入的可用性，不是重新认证或正式数据迁移。L1 仍 FAIL；即使只修复 L2 的代码顺序，也不能跳过修正成员、公告事件、账户守恒和项目的精确哈希迁移门槛。

**可判的 L2 子结论：** 在冻结旧成员、显式定义起始现金与股数、费用、停牌前价盯市、受阻成交和理论指数对冲后，可以对该**条件纸面模型**做完整算术与守恒检验；不需要真实委托回执。该条件检验即使通过，也只能标为“旧污染输入下 L2 纸面账本算术通过”，不能升级为修正后历史收益、真实成交或全层 L2 PASS。若使用者另行选择把 L2 定义为纯机制层，需在裁决里明示其不覆盖 L1 的数据正确性和实际期货可执行性。
