# L2 近期三版本衔接：同批条件诊断

本目录为独立诊断，不写正式源码、`outputs/` 或正式净值。输入是 2025-09-30 以旧有效 100 股、初始 100 万元独立种子建立的新固定股数账户；首个可交易日 2025-10-09，止于 2026-09-30，共 241 日。输入本身沿用尚未通过 L1 的旧目标池；`600543` 自 2026-04-27 已为 *ST，却仍在旧目标/有效池，因此本结果从该日起不可认证为历史正确回测，不能用于生产或正式收益报告。

## 信号与时钟

`rebuild_recent_signals.py` 从新股票账 `equity` 与本日实际费用构造同一已付费持股路径上的本日费前代理增量；仅从旧正式 NAV 读取 `hedge_close`，不读取旧信号或旧股票收益来生成新信号。分别调用正式 v2.0、v2.3、v2.5 纯信号/关闭目标波动分支，得到 `next_session_actionable_scale`。三版在此冻结配置中的 scale 均只有 0/1，`scale_change_cost=0`。T 收盘决定与冻结股数，T+1 收盘纸面成交，新增/退出持仓的收益从 T+2 才变更；订单失败以实际持股为准。

新代理信号有效首日分别为 v2.0 2025-11-03、v2.3 2025-11-12、v2.5 2025-11-05；此前的近 1Y 初期为暖机 N/A。对同样短窗的旧收盘数据重跑后，三版逐日与旧正式信号完全一致；新代理与旧正式信号的差异来自代理路径而非短窗重置。prefunded 分支差异为 8/224、19/217、1/222 日；netted 为 4/224、8/217、1/222 日。逐日比较和首差见 `recent_{branch}_signal_comparison.csv/json`。

## 股票与对冲账户

`strategy_replay.py` 使用新信号及真实逐股原价，在每个版本建立独立的有股数股票账户。入场重新建股篮，退出卖出实际股数；停牌、限价、容量和现金不足订单被拒且留下明细。prefunded 买单只使用成交前已有股票现金；netted 可使用同次收盘卖出所得；两者均不得为股票买单透支。股票每笔成交按单边 0.003 费用入账，分红应收、派付、送转待到账股份单列。

v2.0/v2.3 的 0.8 对冲用**理论零初值、每日按实际股票及待到账权利市值重置的指数互换**建模；每日日内损益使用前一收盘的空头名义额，另按名义额 0.0003 收每日拖累。互换保证金可为负，`swap_debt` 明示借款。为与三版当前正式配置的融资关闭开关对齐，主纸面账应用融资利率为零；另外单列 3% 年率影子融资额，不将其混入主账。此模型不是有保证金、逐笔成交与融资证据的可执行期货账户。v2.5 无对冲或目标波动缩放。

六账户均覆盖 241 日至 2026-09-30，`first_block=null`，股票现金每日非负；v2.0/v2.3 有互换保证金债务，v2.5 为零。旧池 *ST 对策略实际持仓的首日：v2.0/v2.3 两资金分支均为 2026-04-29，v2.5 两分支为 2026-04-27。`audit_strategy_accounts.py` 从 CSV 独立核对每日权益分解、逐股市值、T+1 订单日期、冻结数量×成交价、单边费、股票现金流、互换损益/拖累/名义额，以及所有输入/代码/响应/输出 SHA，六账户均通过；摘要在 `strategy_accounts_audit.json`。
