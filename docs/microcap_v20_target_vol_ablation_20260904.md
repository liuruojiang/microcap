# v2.0 朴素化第五层A：目标波动率开/关消融

## Decision / 结论

keep_default：当前朴素主线保持固定1倍，不加入原15%/75天/最高1.5倍的动态仓位模块。稳定性标记reject，指本轮默认参数的收益/回撤取舍不通过，不是证明所有目标波动率参数均无价值。

本轮只是开/关消融，不是参数扫描。邻域、宽度和网格边界均N/A（未测试），没有据此宣称找到稳健平台。完整生产v2.0参数不变；确认与观察底座也保留，不自动晋升。

## Run Metadata and Research Question

工作目录D:/动量策略/微盘股对冲策略；正式入口microcap_top100_mom16_biweekly_live_v2_0.py。主线16天/零缓冲，确认17天/零缓冲，观察17天/0.003缓冲；均保持R² OFF、过热OFF。原策略对应对照恢复16天/0.003缓冲/60天23%过热，其开启目标波动率的版本就是完整正式v2.0。

每线4种情况：OFF；正式ON；ON仅去掉闲置资金利息；ON让波动输入额外延后一天。4×4=16条日收益流，共80条五窗口结果。plan.md在结果前写定，没有根据结果另增网格。

同线OFF为基准。全样本/10Y/5Y年化损失容忍1pp，3Y/1Y容忍3pp；全样本回撤必须改善、至少3/5窗口改善，浮点噪声容差1e-9pp。当前主线与确认线须同参数都通过；邻域未测，单点即使通过也不具备推广依据。

## Implementation Anchor and Runtime Override Plan

真实apply_target_vol_scaling先从微盘和中证1000价格构造“微盘日收益−0.8×对冲日收益”，以75天样本标准差×sqrt(244)估波动。目标仓位=15%/该波动，限制0至1.5倍；今日实际仓位使用前一日估计，仓位目标与上次执行规模差至少0.10才调整。入场和退出沿用底座持仓信号，不另造择时。

费用继承真实成本模块：出入场各综合0.003、成员按正式调仓日close换手扣费、持仓每日0.00024期货拖累；动态仓位额外同持仓规模换手费率0.001，超出1倍部分年融资3%。少于1倍的闲置资金年收益2%，但仅底座持仓日计息；完整空仓日不计这份利息。继承此正式语义，不把它误称全账户现金收益。

OFF固定1倍，现金和融资为0；ON_cash0只剥离利息，保留融资和交易费，并验证仓位完全相同。ON_lag1只延后波动输入1日，保留正式执行原有1日延后，即波动信息总延后2日；不是完整交易决定延后。所有临时覆盖都在真实函数globals中执行并finally恢复。

固定1倍通过真实目标波动率成本引擎与OFF做等价检查，防止开/关同时换了成本模型。正式完整v2.0与新正式costed CSV在1e-12内一致之后才输出研究指标。当前holding/next_holding字段决定实现收益；overlay_pre_cost_return/base_pre_cost_return为税费前实现收益，不能误用兼容底座return_raw。
