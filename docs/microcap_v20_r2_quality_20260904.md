# v2.0 朴素化第二层：R² 趋势质量过滤

## Decision and stability / 结论

保持 R² 关闭（keep_default），稳定性分类 reject。128 条收益流包括两条关闭基线、126 个启用过滤的候选；通过既定标准的启用候选为 0，连续合格区域为 0。16 天主线和 17 天确认线均不支持加入本轮定义的过滤。

这是“本网格、此种过滤方式不值得加”，不是证明所有 R² 用法都无效。v2.0 本来就未启用该过滤，因此没有删除或修改生产规则。

## Scope / 问题与预注册

项目标准要求：原始动量宽度之后先检验信号质量，再研究后续叠加层。测试方案在候选绩效生成前写入 plan.md，未跳到过热或仓位层。

- 主线 LOOKBACK=16、确认线=17，各自与同一动量窗口的 R² OFF 比较。
- R² 窗口 5、10、15、20、25、30、40；门槛 0.1 至 0.9、步长 0.1。每条动量线 63 个启用组合加 1 个 OFF，共 128 个。
- R² 复用真实函数对“微盘价格 / 中证1000价格”的线性时间趋势计算，不是对数价格、收益率或加权得分的 R²。R² 看平顺程度，不判断方向；原来的正相对动量要求保留。
- 收盘 R² 不达标或缺失时，下一持仓为现金；持仓中也适用。没有分别优化入场、退出门槛。当天已实现收益由上一收盘持仓决定。
- 通过标准：全样本/10Y/5Y 年化损失不超过 1 个百分点，3Y/1Y 不超过 3 个百分点；全样本回撤必须改善，且至少三个窗口改善。没有启用事后放宽规则。
- 后续层不使用第一层的 80% 判据：合格点还要有相邻网格点通过，并在另一动量窗口同一参数上通过。没有合格点，因此不存在可保留的合格连续区域。

激活时微盘 1.0 / 对冲 0.8；信号比较系数仍为 1，不能混用。保留双周调仓、单边入场/退出综合费用各 0.003、正式换手 two_side_cost_rate 按 execution_timing=close 映射，以及持仓每天 0.0003×0.8 期货拖累。融资、现金收益均为 0；不加退出缓冲、峰值衰减、绝对动量、过热和目标波动率。

### 通俗解读

16 天线，不加过滤的全样本年化 23.39%、回撤 14.59%。启用组里年化最高的是 R²20天/0.1：年化 20.39%、回撤 16.32%，收益和回撤两项都不如 OFF。回撤最小的 R²15天/0.3：回撤降至 12.68%，但年化降至 17.08%，付出的收益代价超过预设范围。

17 天线也没有翻转结论：启用组里年化最高点仍比本线 OFF 低超过 2 个百分点，全部 63 点未能通过多窗口收益容忍标准。不是只在 16 天一个窗口上看到失败。

过滤并不保证交易更少。例如 16 天线全样本入场次数，OFF 为 115 次、R²20天/0.1 为 122 次、R²15天/0.3 为 136 次；相应持仓天数占比约 73.27%、67.59%、57.52%。已观察到参与下降而入场增加；低质量退出后再入场可能带来反复切换，但本轮未做零成本归因，不能把全部收益损失归咎于费用。
