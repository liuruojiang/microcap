# v2.3 半衰期扫描：25 / 40 / 60天窗口

## 1. 结论与决策

84组全部真实运行并通过校验，正式策略没有修改。按用户追加要求，在同一组28种半衰期/等权设置上对比25、40、60天窗口。

- 半衰期确实需要单独看。2～3天附近有较强的收益/回撤折中，但它不是对所有时期、所有门槛都稳定的平台；各窗口2.75天虽全样本收益最高，近一年均亏损。不能直接按历史收益峰值选参数。
- 长窗口相同结果主要发生在短半衰期下。半衰期放慢后，40和60天的结果开始分化；此前“窗口宽平台”不能独立于半衰期解读。
- 相比各自2.5天基准，等权均未通过预先规定的简化验收：25天等权全样本年化少1.41pp、最大回撤多11.03pp；40天分别少2.85pp、多6.49pp；60天分别少2.68pp、多3.32pp。完整五窗口差值见附表。等权不是当前可以无代价关闭的参数。
- 25天/2.25天值得保留为附近确认线：相较现行25天/2.5天，五窗口年化均更高，回撤不更差，但其优势仍是历史邻域观察，不是自动替换授权。40天/2.5天作为长期收益观察线继续保留。既有27天窗口研究没有被删除或宣告无效。

Decision: keep_default。保持正式25天/2.5天，完成本层后停止。Stability: narrow_stable，限定为“收益与回撤综合折中的短半衰期区”；不是否认下面仅按全样本收益计算的较宽80%保留区。

## 5. 平台宽度与权重含义

每个窗口下，按全样本峰值CAGR的80%计算，连通的已测试值从半衰期2天延伸到等权；按各窗口2.5天默认CAGR的80%，从1.75天延伸到等权。两侧至少两个邻点的收益宽度标准通过。5天以上网格较疏，这只是连通已测值，不是对未测值插值证明。

但这个收益标准不约束回撤！例如25天窗口半衰期5天的全样本年化仍20.88%，却有29.49%最大回撤。因此不能把“收益没有衰减20%”直接叫作“综合风险稳健”。完整五窗口用于揭示这种差异。

半衰期同时改变趋势分数和R²的权重；R²窗口固定25、门槛固定0.08，但R²数值不会固定。等权是精确的有限窗口普通最小二乘回归：分数窗口25/40/60等权、R²窗口25等权，不是简单区间涨跌幅。
