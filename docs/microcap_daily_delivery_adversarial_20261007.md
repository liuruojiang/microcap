## 修复及对抗复核

- 三版本真实原生入口共用的发布门禁此前可在15:00至15:29继续接受实时数据。已统一为报价时间及实际发布时间严格早于15:00，并在写最终CSV前再次检查，拒绝计算跨越截止的发布；有效历史实时记录仍可在夜间被读取。
- 日报打包器此前按“前一个工作日”推算锚点，错误拒绝长假后的合法报价。已以交易所会话和最终CSV合同核验，继续拒绝缺少中间完整交易日的锚点。
- 最终CSV检查严格拒绝重复表头、重复信号、多行非空记录、长短行及矛盾身份；兼容三版 Windows 原生写入产生的完全空行，不把空行误当第二条信号。版本、参数、持仓和带日期的成员行动均从最终CSV取得。
- 发送端只在SMTP完整接受收件人后原子写收据，核对邮件编号、发收件人、时间及metadata/subject/body内容哈希。未知发送状态阻止盲目重试，旧凭证、类型异常、内容篡改及错误工作流不得恢复成功标记。
- 明确历史验收邮件的独立编号和去重状态；验证模式、休市门禁及正常缓存副作用均有实际工作流条件测试。本地定时任务改为统一17文件门禁并显式使用当前正式打包器，消除旧路径导致静默跳过测试的问题。
