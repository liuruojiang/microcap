## Implementation Anchor / 实际规则

过热不是策略净值下跌止损，也不是价格涨幅23%。真实函数_volatility_overheat_metric计算“微盘日收益−0.8×中证1000日收益”的滚动样本标准差，再乘sqrt(244)。apply_volatility_overheat_exit控制实际持仓和成本。

保留正式两个条件不扫描：本次交易净收益为正才触发；退出后必须等底座信号重置才允许重入。当天持仓先赚取当天收益，收盘触发只改变下一持仓；退出日扣退出费。不是用一个过滤开关事后乘现成净收益。

## Stability Classification / 如何理解

- 16天主线原60天/23%：全样本年化24.10%降至22.68%，回撤14.59%增至14.91%；近一年虽回撤14.29%降至11.28%，年化却19.60%降至3.52%。收益损失不能用轻微减小近期回撤抵消。
- 17天零缓冲：原规则确实改善长期回撤，但5年及1年收益损失超限；0.003缓冲观察线也有保护作用，但同样未过收益门槛。故不是声称“过热规则任何情况下都无效”。
