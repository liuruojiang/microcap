# v2.3 过热波动窗口：两侧宽度与过拟合警惕

## 结论先行

用户关心的是参数两侧能否承受扰动，而不是“开启是否有效”。本轮据此把局部宽度与相对 OFF 的收益取舍分开，不再用后一项替代前一项。

**10天不是孤立最优尖峰，但也不能称为宽而稳的低敏感平台。朴素候选的长期局部平台尚可，近期敏感；原版2.3的右侧更快恶化。**

- 朴素候选：8～15天可看作一个较宽松的局部区域，但不是所有年份都平坦；近一年对9→10天的扰动尤其敏感。单轴过拟合警惕定性为中等，不能评为低。
- 原版2.3：放宽容忍度也只有9～12天连通，到13～15天近期回撤明显变深。相较朴素候选，窗口与R²门槛的搭配依赖更强，定性警惕中等偏高。
- 这不是统计意义上的过拟合概率，也没有证明策略已经过拟合。10天并非全样本与各窗口共同最优，9天也不能因本次回看较好就改成新最优参数。
- 正式2.3不变。窗口之外的触发阈值0.26、恢复比例0.75两轴未在本轮扫描，不能把此结论外推到整个过热模块。

## 两侧到底有多宽

这里“宽度”指**连接当前10天的连续整数区域**，不能跳过中间坏点把远端好点接起来。

标准容忍：相对同线10天，全样本/10Y/5Y年化最多低1个百分点，3Y/1Y最多低3个百分点；每个区间回撤最多加深2个百分点。五个窗口同时满足才计入。这是事前声明的描述性门槛，不是用户已批准的风险预算或过拟合检验。

| 固定线 | 标准容忍连通区 | 左侧支持档数 | 右侧支持档数 | 容忍减半 | 容忍加倍 |
|---|---|---:|---:|---|---|
| 朴素候选 | 9～10 | 1 | 0 | 9～10 | 8～15 |
| 确认线 | 9～10 | 1 | 0 | 9～10 | 8～12 |
| 40天观察线 | 9～10 | 1 | 0 | 9～10 | 8～15 |
| 原版2.3 | 9～10 | 1 | 0 | 9～10 | 9～12 |

**不能把“标准口径只有9～10天”翻译成“11天断崖”。** 朴素候选11天相对10天，全样本年化只低0.34个百分点、全样本回撤只深0.26个百分点；卡在近5年年化低1.33个百分点，略超1个百分点界线。8天也是主要卡近5年低1.54个百分点。原版13天则不同：近5年年化低3.08个百分点，近5年/3年/1年回撤都加深约4.41个百分点，属于更实质的变化。

若要求收益与回撤**上下都接近**10天，而非允许明显改善，标准口径四条线都只剩10天自身：原因包括9天近期表现明显更好，并不意味着10天是孤立高点。因此同时保留“不明显退化”与“对称接近”两种口径，防止误读。

容忍加倍意为长期2个百分点、短期6个百分点、回撤4个百分点；因此8～15天是“宽松支持”，不能偷换成“收益回撤几乎不变”。所有这些局部区域均不触及2或60的网格边界。

## 如何理解过拟合嫌疑

本轮只评价固定阈值下的参数敏感性：

1. 有邻域支持，10不是唯一有效点，反对“明显孤峰”的说法。
2. 两侧宽度不对称且依赖容忍度，原版右侧13天起恶化较明显，反对“很宽、低过拟合”的说法。
3. 五个嵌套回看窗口、四条相关策略线都不是独立样本外验证；参数反复筛选本身仍有数据窥探风险。
4. 远端重复日收益/持仓组已单独留档，不能把完全相同的执行结果当作多份独立稳健证据。并非40～60天全部相同。
5. 不报虚假的“过拟合概率X%”。后续先扫触发阈值的左右邻域，再单独扫恢复比例，最后才有资格评价模块整体宽度；本轮停在窗口轴。
