# v2.0 朴素化第一层：动量底座宽度

## Decision / 结论

保留默认 16 天（keep_default），不修改生产策略。稳定性分类 narrow_stable：全样本与近 10 年的收益宽度通过，但近 5/3/1 年不通过。此标签不代表近期稳健或独立样本外验证通过。

通俗地说：底座不是只有一个参数才能赚钱，但近期成绩对 16 天明显敏感。不能把全样本 13–39 天的收益平台说成“这些参数风险都差不多”，也不能据此认定过拟合风险低。

## Research question / 冻结方案

原阻断记录保留于 ../20260904_v20_momentum_width/；本次沿用事先确定的 plan.md。只扫描 LOOKBACK 整数 5–40，共 36 个；原始动量底座为主，完整 v2.0 为辅助，共 72 条真实候选收益流。

宽度预注册主指标为全样本成本后 CAGR。围绕默认值和峰值分别寻找年化不少于中心 80% 的连续区间；左右各至少两个相邻整数才通过，边界峰值不通过。近 10/5/3/1 年是敏感性检查，不是独立样本外。没有根据结果改变门槛。本轮未扫描 R²、绝对动量、过热和仓位参数。

## Cost and execution / 固定口径

- 朴素底座：动量差大于 0 入场、小于 0 退出，零退出缓冲；无 R²、绝对动量、衰减、过热和目标波动率。激活时微盘 1.0 / 对冲 0.8，空仓现金收益和融资成本为 0。
- 入场、退出综合交易费各 0.003，不另重复叠加佣金滑点。持仓每日期货拖累 0.0003×0.8=0.00024。成员调仓费复用正式 two_side_cost_rate，按原 execution_timing=close 映射，不改变信号与收益先后关系。
- 完整 v2.0 保留缓冲 0.003；过热窗口 60 / 阈值 0.23 / 正交易收益前提 / 信号重置；目标波动率 15%、窗口 75、规模 0–1.5、规模调仓阈值 0.10、交易费 0.001；融资率 3%、现金收益 2%、年交易日 244。
- 年化按日历跨度/365.25 复利，波动率按样本标准差×sqrt(244)，仓库 Sharpe 为年化/波动率，不扣无风险利率。
- 两栈不仅差一个规则，现金收益、融资、规模也不同，不能把差异归因于某一个叠加层。未做成本或数据口径扫描。
