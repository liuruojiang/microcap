## 已修复的问题

- 仅凭“撤销退市风险警示”的标题，无法断定其他风险也已撤销。600180 的 2011-12-14 原公告明确仍实施其他特别处理；直到 2012-08-31 公告才撤销其他风险。现在按经审阅的原文动作保持连续 ST。
- 000677 的 2016-03-24 原公告已批准退出；合并名称变更的既有 inclusive 口径后，旧 2015 年区间结束于 2016-03-25，与 2026-04-30 重新进入分离，不再错误延续至今。
- “将被实施”、问询和第三方主体标题不能独立证明本发行人的有效状态。无正文认证时明确阻断；已核实决议的未来生效公告沿用现有公告日排除口径，不擅改为生效日。
- 同日相反状态、公告主体错配、同一公告 ID 内容冲突、已认证公告缺失或原件哈希不符均明确失败，不能被普通网络失败处理吞掉后复用旧历史。
- 旧解析器与此前修复曾共用 v3 政策标识。新 metadata 增加独立解析器修订标识及正文证据指纹；存在历史 ST 的旧记录缺少这些证明时拒绝静默复用。
