# v2.5 朴素化：七条动量线的半衰期宽度

## 结论

半衰期的效果不是只存在于一个点，但“加权优于无加权”与“精确最优点周围很平坦”是两回事。

- 30天、40天线有较宽的相对改善区间；25天、60天也有两侧支持。
- 20天线相对纯涨幅看似很宽，但相对等权斜率只剩半衰期2.75一个点通过严格标准。因此不能把20天线的全部改善归功于半衰期。
- 14天、17天线，没有半衰期同时满足五窗口收益容忍度与回撤改善标准；这不等于证明规则无效或已经过拟合。
- 25/30/40/60四条线共同通过两个对照的连续已测区间为2.5–3.5天（2.5、2.75、3、3.25、3.5）；保留七条线，不擅自删线。
- 若把半衰期3天的五窗口表现当作更严格的局部参考，大多只剩一个点或单侧邻点。不能把3天描述成“峰值周围很宽、随便调都一样”。
- 结论为 **watchlist / narrow_stable**：相对改善有平台，精确参数值仍有选择风险。仅历史研究，未变更正式策略。

## 口径与边界

沿用用户授权的旧代码与旧冻结数据。原始价格4033行，2010-01-28至2026-09-04；统一回测3971行，2010-05-05至2026-09-04。历史换篮431次，最后执行2026-09-03。这不是当前线上同步或正式数据验收结论。

信号为未对冲微盘净值的指数加权对数趋势斜率；入场和退出均为0，仓位0/1；无目标波动率、融资、现金收益、对冲、R2门槛或过热条件。旧原版17/3/0.46/0.25仅作单独对照。

半衰期越小，越重视最近数据。等权为关闭时间衰减。原始N日涨幅没有半衰期；旧官方WLS的N天指N个价格观测（N-1个间隔），纯N日涨幅则为N个间隔。因此用同N的等权斜率隔离“半衰期加权”的影响。

所有数值由旧v2.5真实函数链跑出，含原费用：入/出场各0.3%，换篮成本按冻结表计入。昨日确定的持仓控制当日收益，收盘状态变化计费。未增加费用敏感性测试，也未额外模拟价限、冲击、容量和T+1压力。

公共原始价格代理口径，并非Wind官方指数；沿用历史成员/ST等构建假设，保留688592历史政策证明缺口。没有新样本外检验，各回看窗口重叠，无法给出“过拟合概率”。

## 如何判定宽度

标准在运行前已写入 protocol.md：相对同一条基线，全样本/10年/5年年化最多落后1个百分点，3年/1年最多落后3个百分点；全样本回撤必须改善，且五窗口至少三个回撤改善。分别比较纯涨幅与等权斜率，两者都通过才称为双对照改善区间。

另列严格局部稳定区间：相对同线半衰期3天，上述收益容忍度不变，每个窗口回撤恶化不得超过2个百分点。它只是敏感度检查，不是加权层通过标准。

区间仅代表连接的已测点；步长不均，未测内插点不构成证明。*表示碰到网格边界，边界以外未知。单个点、分离区间和单侧区间不得说成两侧宽平台。
