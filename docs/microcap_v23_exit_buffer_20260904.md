## 1. 结论

退出缓冲不宜像 R² 那样直接删除。研究主线（动量25天/半衰期2.5/R²关闭）保留原缓冲0.08，比缓冲0的全样本年化高1.77个百分点，最大回撤低1.02个百分点；近5年、3年、1年回撤基本不变。删除没有换来近期风险改善。

暂时保留0.08，不改为历史收益最高的0.30。0.07与0.08结果接近，缺乏为了朴素化再精确调小0.01的必要。0.14提高长期收益，但近1年收益少2.63个百分点、回撤大2.25个百分点；0.30近期损失更明显。

必须区分两个结论：
1. 删除原有缓冲不划算，支持暂留现行0.08。
2. 按事前“全样本回撤改善且至少3/5窗口回撤改善”的严格新增防御准入，研究主线没有正缓冲通过；0.08只改善两个回撤窗口，另外三个不变，不能写成通过强防御筛选。本轮没有改动准入标准来迁就结果。

四条线中，严格数值准入仅有确认线0.15、40天线0.07通过，均缺少通过该规则的相邻点，不能直接升级。decision=keep_default，指主线维持缓冲0.08及生产不改；stability_label=peak_only，指严格准入合格点在其他线中呈孤点形态，不是宣称0.08是最优或全样本收益峰值。

下一层建议先做过热防御开关消融，再决定是否需要细扫过热参数。本轮未测过热、未改生产、未推送、未发邮件、未下单。

## 4. 邻域、近期风险及准入

- 研究主线：没有正缓冲通过该严格规则。0.07/0.08分别较缓冲0提高全样本年化约1.73/1.77pp，改善全样本及10Y回撤，近期三档回撤不变，是“不宜删除”的证据，不是强防御准入成功。
- 半衰期2.25确认线：仅0.15通过，五个回撤窗口都较缓冲0改善。0.14的全样本回撤不合格，0.16近5年/3年/1年回撤变差，因此0.15是待核验孤点，不自动改为0.15。
- 40天观察线：仅0.07通过，第三个改善窗口是近3年，幅度约0.06pp。0.06只有两个回撤窗口改善，0.08近期回撤变差，故不能夸大0.07精确值的稳健性。0.06—0.07可作近期更均衡的观察区，但未升级原40天对照。
- 原完整2.3：没有正缓冲通过严格规则。缓冲0可减少全样本及10Y回撤，但收益损失超过1pp长期容差，近期回撤不变，不能把它描述成无代价优化。
