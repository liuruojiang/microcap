# v2.3 朴素化：R² 入场门槛扫描（2026-09-04）

## 结论

主线 25 天 / 半衰期 2.5 天的现行 R²≥0.08 过滤，没有显示出值得保留的收益回撤权衡：关闭后五个区间年化收益全部提高，四个区间最大回撤改善，只有近 5 年回撤恶化 0.77 个百分点。40 天 / 2.5 天对照线关闭后，五个区间收益和回撤全部改善。

但 25 天 / 2.25 天对照线不同，较低的 R² 门槛仍有作用。不能把“当前主线的过滤不划算”推广成“所有半衰期下 R² 都无用”。这也提醒我们，继续挑选半衰期和门槛组合会增加过拟合风险。

研究决策：主线与 40 天对照线的 R² OFF 进入简化候选；25 天 / 2.25 天低门槛分支保留为确认对照。正式 v2.3 参数尚未修改。本层完成即停止；下一项可测试 R² 计算窗口，之后再决定是否整项删除，不在本次同时扫窗口。

## 通俗解释与测试范围

R² 衡量最近走势对一条趋势直线的贴合程度；门槛越高，空仓后重新入场越挑剔。它不负责把已持仓位赶出去，退出仍由动量分数及过热规则控制。

本轮只改 R2_ENTRY_GATE。R2_WINDOW 固定 25；每条对照线内动量窗口和半衰期固定。三条线是前轮已确定的主线、邻近确认线、长窗口观察线，不是新做联合寻优。没有重复费用扫描。

门槛网格：关闭（0）、0.01、0.02、0.04、0.06、0.07、0.08、0.09、0.10、0.12、0.15、0.20、0.25、0.30、0.40、0.50、0.60、0.80，共 54 组。有效 R² 被截在 [0,1]，因此门槛 0 等于取消此项入场限制；正动量入场和负动量退出仍保留。

## 事前准入规则与邻域判断

- 25 / 2.5：没有一个正门槛通过。
