# v2.5 动量基座与加权半衰期敏感性研究（2026-10-03）

## 研究范围

本轮按顺序只变动一项参数。第一轮固定正式半衰期 3.0，将动量基座从 5 日扫至 100 日、步长 5；第二轮根据第一轮结果固定正式基座 20 日，将加权半衰期从 1.0 扫至 5.0、步长 0.1。正式 v2.5 的进/出场阈值均为 0、执行对冲比例 0，目标波动率、现金收益和融资叠加均关闭；两轮均未更改生产配置。

数据与执行路径取自 `microcap_top100_mom16_biweekly_live_v2_5.py` 及其正式基础数据。扫描前全工作区交付检查通过；面板 8738 行、代理指数 4067 行、v2.0 基础成本后 NAV 4050 行及正式 v2.5 成本后 NAV 3988 行，末日均为 2026-09-30。统一绩效窗口是 2010-07-01 至 2026-09-30 的 3950 个交易日。以正式成本后模型计入进/出场与成员换仓成本，收盘信号决定下一交易日目标持仓。

## 关键结果

下表为年化收益 / 最大回撤；各列共用同一数据、成本与日期窗口。

| 窗口 | 正式：基座20日、半衰期3.0 | 第一轮全样本峰值：25日、3.0 | 第二轮全样本峰值：20日、3.7 |
| --- | ---: | ---: | ---: |
| 全样本 | 33.46% / -27.65% | 33.91% / -28.64% | 36.15% / -24.52% |
| 近10年 | 21.42% / -27.00% | 20.98% / -23.72% | 21.28% / -24.52% |
| 近5年 | 34.36% / -20.29% | 32.25% / -21.20% | 30.14% / -22.47% |
| 近3年 | 37.93% / -19.72% | 35.28% / -19.37% | 34.17% / -20.19% |
| 近1年 | 29.08% / -12.88% | 20.87% / -14.37% | 23.82% / -12.88% |

第一轮 25 日的全样本年化只比正式 20 日高 0.44 个百分点，近一年则低 8.21 个百分点。60–100 日九档虽然分数不同，逐日持仓、成本和收益路径相同，不能视为九次独立稳健性验证。

第二轮半衰期 3.5–3.9 在全样本形成连续较高区域，3.7 最高；但该区域近 5 年和近 1 年收益都低于正式 3.0。将 3.7 与正式 3.0 的收益差按时期分解，2010-07 至 2016-09 的优势约为年化 8.54 个百分点；2021-10 至 2026-09 则落后约 4.23 个百分点。3.7 的全样本优势主要由早期贡献。近一年 3.4–3.7 日共用一条交易路径，3.8–3.9 日也共用一条，近期平台同样不能当作多次独立验证。

## 核验与决策

正式参数逐日重算与官方 v2.5 成本后文件的日期及 21 列一致（3988 行）。独立复算从冻结代理收盘重新得到持仓收益、成本后收益和净值，并核对两轮共 305 个窗口指标；未发现数值差异。扫描产物的严格完整性检查均通过。

**保留正式 `LOOKBACK=20, HALFLIFE=3.0`。** 25 日与半衰期 3.7 均为样本内研究候选，不晋级生产。结果继承当前代理成员、历史 ST、公司行为及纸面执行模型的既有边界，不构成历史数据或可成交性的重新认证。
