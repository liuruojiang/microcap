# v2.5朴素化：关闭半衰期和非零门槛，只扫原始动量天数

## 1. 结论与决策

完成5—60天逐日56档纯动量回测，并在同批次重跑原版2.5对照，共57条日流。用户明确授权“这些不影响的，你可以先按旧的来测”，因此采用上一轮冻结数据和不可变旧源码；这是历史快照研究，不是当前同步验收，也未更新正式策略。

- 纯动量全样本收益及全样本Calmar高点均为14天；不是此前加权回归的17天。
- 围绕14天，保留至少80%全样本年化收益的连续区间9—21天（左5、右7），不是单一收益尖峰。
- 围绕14天，五个时期各自收益均保留至少80%的连续区间只有13—15天（左1、右1）；再要求各期最大回撤最多加深2pp，只剩14天。全样本Calmar80%区间13—18天（左1、右4）。
- 围绕同家族raw17，收益80%连续区间9—23天（左8、右6），五窗收益80%为16—18天，叠加DD2pp约束只剩17天。
- 长窗口不再表现为此前约20—60天的平坦收益尾部，说明此前平台是“短半衰期+两个得分门槛”条件下的表现，不能直接归因于原始动量天数。
- Decision=watchlist；Stability=narrow_stable，限定为五窗共同支持的小区间，不否认全样本收益9—21天较宽。原版2.5不变；纯动量14天只是全样本高点观察线，raw17及相邻13/15/16/18保留作确认，没有选定新正式参数。

## 2. 这次究竟关闭了什么

纯动量定义M_N(t)=P(t)/P(t−N)−1，M_N(t)>0安排持有，否则空仓。零是固定正负边界，不是新拟合阈值。
- 不用HALFLIFE指数权重，不做log-WLS或其他趋势回归。
- 不用0.46入场门槛和0.25退出门槛，不保留持仓缓冲区。
- 不用R²、过热、峰值衰减、止损、目标波动、融资、现金日收益或对冲。
- 保留Top100股票池及原有双周成员日历、原有费用和滞后执行时序；微盘暴露为0/1。
- N是过去N个收益间隔，即使用相隔N个交易日的两次价格；原版WLS使用N个价格观测，二者窗口定义不同。
- 收益平滑不是计算上的“去掉半衰期但保留等权回归”；本轮明确用原始区间涨幅，符合纯动量底座研究。

## 5. 宽度边界的正确解释

事前protocol.md冻结：全样本收益80%、五窗各自收益80%、后者加各窗DD最多加深2pp、辅助全样本Calmar80%；只统计含锚点的连续区间，孤立通过点不拼接。

围绕14天，五窗收益区间13—15天的右侧边界不等于16天全面崩溃：raw16的近10年收益15.18%略低于raw14的80%门槛约15.22%，因此被严格比例标准截断；但raw16近期收益高于raw14。不能把一个人为容差边界直接当成“明确发生过拟合”。

围绕raw17，所有窗收益保留80%的其他孤点9天、56天不与16—18天相连；不得称为9—56天宽平台。围绕14天也有9、11、17、18等断开的合格点。宽度文件保留全部合格集合。

本轮56档没有整条持仓/收益完全相同的重复组；各相邻N都检查了分数、持仓和日收益差异。此前长窗口相同收益的解释不能套到这次纯动量上。

过拟合评价：纯动量并非只在一个天数赚钱，全样本邻域有支持；但兼顾多个时期和回撤时，支持区间变窄，仍有明显参数/时期敏感性。不能给出“过拟合概率xx%”，也不能称纯动量已经足够稳健或其少参数必然更好。
