# v2.3过热恢复阈值：19.5%两侧宽度

## 结论先行

**恢复阈值有较明确的双侧平台，19.5%不是孤立尖峰。这一轴比上一轮触发阈值轴更宽。**

- 四条线共同“不明显退化”区间18%～22.5%，相对19.5%向左1.5个百分点、向右3个百分点。
- 原版2.3单独可到18%～23.5%，左1.5、右4个百分点。
- 要求收益/回撤上下都比较接近19.5%，四条线共同区间18%～22%，左1.5、右2.5个百分点。
- 以上按0.5个百分点网格；不证明每个更细小数阈值都已验证。18.5%、19%、19.5%三个已测值实际执行/收益完全相同，不能当作三份独立样本。
- 恢复这一单轴的孤峰型过拟合担忧相对较低，有较宽局部支持；不是统计意义的过拟合概率，也不表示整个策略已排除过拟合。
- Decision=keep_default，当前19.5%不改；本轮不是推荐某个更高收益点替换正式参数。Stability=wide_stable，标签仅指固定触发26%/窗口10的恢复轴，不代表整个过热模块。

## 定义与单参数边界

正式规则：波动率>=26%时触发防御；进入防御后，波动率<=恢复线才解除防御。解除防御仍需底层信号要求持仓才实际入场。恢复线越高，通常越早允许恢复；越低，等待降温越久。整体交易路径和收益并不保证单调。

- 固定触发26%、波动窗口10天，只扫恢复绝对阈值0%～25.5%，每0.5个百分点，共52档。
- 当前19.5%对应恢复比例75%；每个候选的比例派生为恢复线÷26%，不是第二个独立参数。
- 26%及以上违反“恢复线必须低于触发线”的规则，不纳入本轮。
- 0%是极端恢复条件，不是关闭过热防御。OFF另有独立对照，网格CSV以-1标记，运行时触发无穷大。
- 四条固定线：formal25/2.5/R².08、primary25/2.5/R²OFF、nearby25/2.25/R².08、watch40/2.5/R²OFF；均R²窗口25、离场缓冲.08。
- 52×4+4OFF=212组。费用、执行、数据、样本不变，不测试费用、不运行二维组合。
- 采用 quant-param-scan 单轴规范与 quant-research 真实代码/数据/独立回放规范；事前协议保存在quant_param_scan_runs/20260904_v23_overheat_recovery_width/protocol.md。
