# v2.0 朴素化第三层：退出缓冲

## Decision and stability / 结论

主研究线继续16天动量、R²关闭、零退出缓冲（keep_default）。不把17天线上找到的好点直接移到16天，不修改完整生产v2.0的0.003。

稳定性标记 narrow_stable：仅17天线存在0.0015–0.005的本线合格连续区间，共8个点；16天线无合格点，跨动量窗口确认通过数为0。因此这是参数搭配敏感的观察区，不是全局稳健区。

保留17天/缓冲0.003为观察线；16天/0和17天/0仍是下一层承接对照。现有0.003在完整生产栈中的作用与朴素底座不同，不能仅凭朴素线结果直接从生产删除。

## Research question / 预注册

本轮沿用前两层顺序，只检验退出缓冲，方案在plan.md中先于候选绩效写入。原始主线和确认线固定LOOKBACK16/17、R² OFF；基准各为0缓冲，当前正式对应条件0.003也在同次运行中。

扫描缓冲0、0.0005、0.001、0.0015、0.002、0.0025、0.003、0.0035、0.004、0.0045、0.005、0.006、0.007、0.008、0.009、0.01，共16值×2线=32条朴素收益流。另做4条完整v2.0固定规则下的0/0.003侧面对照，没有扫描过热或目标波动率参数。

门槛不变：全样本/10Y/5Y年化损失<=1个百分点，3Y/1Y<=3个百分点；全样本回撤改善，至少3/5窗口回撤改善。浮点噪声容差1e-9个百分点，不把约1e-14的差异当改善。后续层宽度是相邻点满足同线门槛并在另一动量线同参数得到确认，不使用第一层80%规则。

## Implementation / 真实路径

源码 microcap_top100_mom16_biweekly_live_v2_0.py：正式退出缓冲常量0.003，首次状态消费函数apply_momentum_gap_exit_buffer。原生产函数语义：空仓时gap>0才入场，持仓时gap>=-buffer继续持有，低于阈值才退出。0.003是相对收益差0.3个百分点，不是相对动量乘0.3%。

候选直接调用正式buffer状态机，再调用apply_momentum_gap_no_peak_decay_cost_model；完整栈侧面对照继续调用真实过热退出和目标波动率。仅在研究进程中覆盖LOOKBACK属性及真实函数全局表，异常也恢复。未修改生产源码、费用、authority或历史成员政策。

## Interpretation / 为什么不能一刀切

- 16天朴素线：0.003全样本年化仅增加0.19个百分点，回撤却从14.59%增至20.02%；5Y和1Y收益也超出容忍损失。虽然全样本入场从115减为94次，不能因此判为划算。
- 16天的小缓冲0.0005全样本略有改善，但仅全样本回撤改善、其他窗口无相应改善，不满足至少三个窗口要求，也没有得到17天同点确认。没有为了它事后放宽标准。
- 17天朴素线：0.0015–0.005的8个相邻值按本线标准通过，0.003全样本年化增加2.01个百分点，回撤仅改善0.27个百分点。说明这段收益增益和动量窗口有关，保护幅度较小，不应夸大为强防御层。
- 完整v2.0的16天线：保留0.003的全样本年化26.58%、回撤17.57%，去掉后25.66%、21.01%。近一年去掉缓冲更好，但长期不能据此忽略。17天完整栈也有保留缓冲的长期优势。

所以上述结论只支持朴素16天研究线继续用0，不授权从完整生产v2.0删除0.003。具体是哪一个后续模块产生交互，本轮未做额外消融，不能仅凭侧面对照归因给过热或目标波动率中的某一个。
