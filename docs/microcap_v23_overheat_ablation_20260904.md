# v2.3 朴素化：过热防御开关消融（2026-09-04）

## 1. 结论与决策

现行过热防御确实降低回撤，但收益代价超过事前标准，不能无条件原样保留，也不能说“没有作用”。

研究主线（动量25天/半衰期2.5天/R²关闭/退出缓冲0.08）：
- 保留相对关闭，全样本年化少0.59pp，回撤改善3.65pp；这项长期权衡本身不差。
- 近5年年化少1.67pp，超过预定1pp容差。
- 近1年年化从关闭时17.09%降到保留时5.77%，少11.33pp，超过预定3pp容差；同时回撤从16.58%降到9.43%，改善7.15pp，是实质性风控效果。
- 因此当前ON配置未通过多窗口收益容差，关闭进入简化研究候选。但关闭意味着更高回撤，不能称为无损优化。

另外三条线也没有通过事前准入：确认线和40天观察线的近期收益损失同样很大；原完整2.3的全样本最大回撤没有改善，收益却减少。

额外延迟一天过热特征后，主线五个区间回撤仍比关闭低，说明不是仅靠精确当天触发产生的假效果。但延迟方案同样不满足收益容差，且仅为诊断，不作为新候选寻优。

decision=watchlist：保留ON作为风险对照，OFF作为简化候选；正式生产不动。stability_label=reject：仅指现行ON配置未通过冻结的收益回撤准入，不是否定过热防御这一类方法。

本轮只做开关消融，未证明阈值或窗口平台宽度。下一项可单独扫描过热波动窗口（现行10天），固定触发0.26、恢复0.195，检查是否能减少收益牺牲；本轮未做该扫描。不要把ON/OFF结果当成所有过热参数已测完。
