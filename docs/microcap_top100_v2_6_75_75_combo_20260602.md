# Microcap Top100 v2.6 75/75 Combo - 2026-06-02

## Summary

`v2.6` promotes the tested 75/75 portfolio combination into a formal close-confirmed version:

```text
v2.6 = 0.75 * v2.3(tv26, max_leverage=1.0)
     + 0.75 * v2.5(tv26, max_leverage=1.0)
     - portfolio-level financing cost
```

The version is implemented in `microcap_top100_mom16_biweekly_live_v2_6.py`.

## Source Sleeves

- `v2.3` sleeve: spread-NAV log-WLS signal, execution hedge 0.8x, target volatility 26%, max leverage 1.0x.
- `v2.5` sleeve: microcap-only log-WLS threshold signal, target volatility 26%, max leverage 1.0x.
- Both sleeves are rebuilt from the same refreshed embedded `v2.0` base and turnover inputs.

## Combo Cost Rule

Bottom sleeve `return_net` already includes each version's own current cost, cash-yield, target-vol scale-change, and financing conventions.

The combo layer adds only the portfolio borrowing cost:

```text
daily_combo_financing = max(0.75 + 0.75 - 1.0, 0) * 3% / 244
```

No extra rebalance cost is added between the two strategy sleeves.
