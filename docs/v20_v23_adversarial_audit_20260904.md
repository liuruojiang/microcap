| 非有限 / 非固定尺度及矛盾动作别名 | Inf 仓位或 cash→cash 被写成开仓 | 尺度校验；动作由已验证持仓与尺度推导 |
| 历史名单行动被当作当前行动 | 旧调仓重发 | close 绑定本次信号日，realtime 绑定本次执行日；required / official 须明确为真 |
| 新实时日志可搭配旧收盘 CSV | 混用日期及信号模式 | CSV 当日报价、带时区快照、前一完成交易日锚点及盘中模式必须一致 |
| v2.3 修订字符串正确但开关相反 | 参数混用仍被接受 | 验证 R²、信号对冲、入场、退出缓冲、现金收益与融资开关；兼容 NAV / signal 的正式入场字段别名 |
