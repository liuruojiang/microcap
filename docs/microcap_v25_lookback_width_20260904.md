# v2.5 朴素化第一项：17天动量窗口的双侧宽度

## 1. 结论与范围

56档（5—60天逐日）均完成真实数据回测，固定半衰期3天、入场0.46、退出0.25。未更改正式v2.5，也未扫描其余三项。

结论是“收益平台宽，但17天的低回撤优势窄”，不能混成一个无条件的稳健标签。
- 全样本收益保留基准17天至少80%：14—60天连续通过，左3天、右至少43天。以全样本收益最高18天的80%为标准，仍是14—60天；17不是收益孤峰。
- 五个区间收益各自保留17天基准至少80%：14—29天，左3天、右12天。
- 再加每个区间最大回撤最多加深2个百分点：只剩17天，左右相邻均未通过。
- 辅助非明显退化规则（Full/10Y/5Y年化损失≤1pp，3Y/1Y≤3pp，各窗回撤加深≤2pp）也只有17天。容差减半仍只有17；加倍才是17—18，依然没有左侧支持。对称接近标准在双容差下也只有17。
- Decision=keep_default：暂不凭样本内表格替换17天。Stability=peak_only特指其低回撤/收益回撤综合形态，不是说长期收益呈孤峰。
- 过拟合判断：17这个精确天数的收益孤点嫌疑较低；若依据17天明显较低的最大回撤选它，则过拟合疑虑较高。没有统计方法估计“过拟合概率”，不提供伪精确百分比。
