# v2.3朴素化：参数清单与第一层窗口宽度（2026-09-04）

## 结论

第一层已实测10～60天共51个整数窗口。**25天保留作当前基准，不认定为最优参数；27天作邻近确认线，40天作长窗口观察线。正式2.3及日报未修改。**

全样本窗口宽度通过，但五个窗口同时要求不低于25天年化的80%时，仅25～27天形成连接区域，左侧24天就不通过。结论为“长期宽、近期窄”，稳定性分类 `narrow_stable`；不能说整个动量底座已经去过拟合。

### 宽度和一日敏感性

- 预先选定宽度指标为全样本CAGR；两侧各至少2个相连整数窗口达到中心值的80%。
- 25天中心：80%连通区间11～60天，双侧通过；右端达到扫描边界，不宣称60天以外已验证。
- 全样本峰值首次出现在40天，80%连通区间14～60天；40～60天收益已经形成近乎相同的平台，不把40当作精确最优数字。
- 近1年，25/26/27天年化4.83%、回撤10.95%；24、28、40天约2.22%、回撤13.16%。25天与24/28/40天在近1年仅有2026-03-23这1个实际持仓日不同。
- 2026-03-20，24天得分-7.9548%、25天-8.1587%、27天-8.1297%、28天-7.9783%，恰好分布在-8%退出线两侧。25～27天次日空仓，其他所列窗口持仓并在3月23日录得约-2.7803%成本后回报。
- 这说明近1年的优势依赖一次阈值跨越，不能当作稳健的最优参数证明；也不能用全样本更好的40天掩盖近期损失。
