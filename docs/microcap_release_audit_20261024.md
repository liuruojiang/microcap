## 本轮独立对抗审计

三个 Agent 分别审阅报价与发布时点、ST 与历史数据、日报交付链。反例使用明确标识的合成输入；真实数据的验证单独记录。

- 报价必须同时保留提供方时间与接收时间；无效最新价不能伪装为前收盘价。缓存、成员覆盖和最终发布都执行来源与有效期校验。
- ST 状态按风险类别维护；混合撤销、继续实施、部分撤销和重复退出不能造成错误摘帽。本轮又修复了省略重复动词时丢失“部分”限定，以及把“拟撤销”当作已生效的两个边界。87 组现有真实公告在本轮追加修复前后结果一致，内嵌和独立实现一致。
- 发布提交前必须再次校验时点与报价有效期，避免指纹计算、序列化或写入重试跨过 15:00 或有效期后仍发布实时文件。
- 云端需要同步不可变策略提交、完整状态包、三个 checkout 和回归清单；只推送策略代码不能证明日报更新成功。
